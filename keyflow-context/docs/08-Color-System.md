# 08 - Color System

Version: 1.0  
Project: KeyFlow  
Status: Draft  
Document Type: Design System  

---

## Purpose

The Color System defines every color used throughout KeyFlow.

No component, page, animation, chart, icon, or state should introduce arbitrary colors.
Every color must originate from this document.

---

## Dark Theme Palette

### Backgrounds
- **Primary Level 0**: `#090B10` / `#060608` (Base Canvas)
- **Secondary Level 1**: `#0E1117` / `#0D0D12` (Panels, Header)
- **Tertiary Level 2**: `#151922` / `#13131A` (Cards, Bento)
- **Elevated Level 3**: `#1B202A` / `#1A1A24` (Dialogs, Popovers)
- **Highest Surface Level 4**: `#232A35` / `#21212E`

### Text Colors
- **Primary**: `#F8FAFC` / `#E2E2E2`
- **Secondary**: `#CBD5E1` / `#9A9A9A`
- **Muted**: `#94A3B8` / `#404040`
- **Disabled**: `#64748B`

### Brand & Accents
- **Brand Primary**: `#4F8CFF`
- **Ember Accent**: `#F0A968`
- **Success**: `#22C55E` / `#34D399`
- **Warning**: `#F59E0B`
- **Error**: `#EF4444` / `#FF3B30`
